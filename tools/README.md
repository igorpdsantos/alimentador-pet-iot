# Ferramentas

| Pasta | O que é |
|---|---|
| [`dem_dosador/`](dem_dosador/) | Simulação por elementos discretos (DEM) do rotor dosador, usada para escolher o "chapéu" P10 que alivia o peso da coluna de ração. Resultados em `docs/estudos/chapeu/` |
| [`simulador/`](simulador/) | Simulador do ESP32 no MQTT, com broker local opcional, para desenvolver e apresentar o app sem hardware |
| [`protocol-fixtures/`](protocol-fixtures/) | Exemplos JSON do contrato MQTT, usados pelos testes do firmware e do app |
